🚨 HyperAid – AI-powered emergency response and assistance platform.
🗺️ Live Map – Finds nearby hospitals, ambulances, police, fire stations, and pharmacies.
📍 Location Services – Provides nearby emergency services based on the user’s location.
🤖 HYPER AI – Offers instant emergency guidance and basic first-aid assistance.
🎙️ Voice Assistant – Supports voice-based interaction for quick hands-free help.
⚡ Emergency Dashboard – Shows nearby emergency services in one simple interface.
🚑 Accident Detection – Provides basic accident severity estimation from uploaded images.
🆘 SOS Alerts – Helps users quickly notify saved emergency contacts.
📡 Live Tracking – Enables temporary GPS location sharing with trusted contacts.
⚠️ Community Alerts – Displays local accidents, floods, roadblocks, and emergency reports.
🏥 Medical Card – Stores essential emergency medical information for quick access.
💻 Tech Stack – Built using Flask, Python, SQLite, Bootstrap, JavaScript, Leaflet, and OpenStreetMap.
